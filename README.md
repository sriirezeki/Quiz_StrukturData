Deskripsi Program

✨ Program 1: Sistem Pengelolaan Nilai Mahasiswa

Program ini mengelola data nilai mahasiswa dengan menggabungkan dua struktur data. 
Linked List menyimpan data lengkap mahasiswa (NIM, nama, nilai), sedangkan Dynamic Array menyimpan kumpulan nilai saja. 
Dynamic Array diurutkan dengan Insertion Sort dan dicari dengan Binary Search. 
Pencarian berdasarkan NIM dilakukan dengan Linear Search pada linked list. 
Program menolak NIM ganda dan memvalidasi nilai pada rentang 0 sampai 100.

Fitur:

Tambah data mahasiswa

Tampilkan data mahasiswa dan kumpulan nilai

Urutkan nilai (Insertion Sort)

Cari mahasiswa berdasarkan NIM (Linear Search)

Cari nilai tertentu (Binary Search)

✨ Program 2: Sistem Antrean dan Pengelolaan Buku Perpustakaan

Program ini mensimulasikan layanan perpustakaan dengan tiga struktur data berbasis linked list. 
Queue (FIFO) mengatur antrean mahasiswa peminjam, Stack (LIFO) mencatat riwayat pengembalian buku, dan 
Binary Search Tree menyimpan ID buku yang tersedia serta dipakai untuk memvalidasi peminjaman dan pengembalian. 
ID buku yang sama ditolak. Isi BST dapat ditampilkan dengan traversal Pre-Order, In-Order, dan Post-Order.

Fitur:

Tambah mahasiswa ke antrean (enqueue)

Proses peminjaman mahasiswa terdepan (dequeue)

Catat pengembalian buku (push)

Hapus riwayat pengembalian terakhir (pop)

Tambah ID buku ke BST

Cari ID buku di BST

Tampilkan traversal BST

Tampilkan semua data

✨ Program 3: Sistem Pencarian Rute Lingkungan Kampus

Program ini memodelkan enam lokasi kampus (A sampai F) sebagai graf berbobot tidak berarah yang disimpan dalam adjacency matrix 6x6, 
dengan bobot berupa jarak antarlokasi. Program menyediakan penelusuran BFS (berbasis antrean), penelusuran DFS (berbasis rekursi), 
dan pencarian rute terpendek dengan algoritma Dijkstra lengkap dengan urutan lokasi dan total jarak.

Fitur:

Tampilkan hubungan antarlokasi

Telusuri graf dengan BFS

Telusuri graf dengan DFS

Cari rute terpendek (Dijkstra)

✨ Program 4: Sistem Data Mahasiswa dengan Hash Table

Program ini menyimpan data mahasiswa (NIM sebagai kunci, nama sebagai nilai) dalam hash table berukuran 20 slot. 
Tabrakan (collision) ditangani dengan open addressing memakai double hashing: 
hash1 menentukan posisi awal dan hash2 menentukan ukuran langkah. 
Penghapusan memakai lazy deletion (status DIHAPUS) agar rantai probing tidak terputus. 
Program mencatat setiap collision beserta nomor percobaannya, menolak NIM ganda, dan menyediakan 15 data uji.

Fitur:

Insert data mahasiswa

Search data mahasiswa

Remove data mahasiswa

Display hash table beserta status tiap slot

Muat 15 data pengujian
